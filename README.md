#Use of Climber-X
All files within the CLIMBER-X folder are either derived from, or built to work with, the Climber-X climate model
The Climber-X climate model was created by the Potsdam Institute for Climate Impact Research in Fortran. For use in EXcalibur, I have hand-converted the model into GDscript, and transitioned the model to a Geodesic grid.
While EXcalibur is also under a GNU General Public License, for the sake of clarity, a seperate license for Climber-X is provided as the Climber-X materials are based on the Climber-X program.
